# ok-script-linux

Pure Linux & Proton automation framework for `ok-script` game automation applications.

## Features

- **Zero-Copy Capture**: Native Vulkan Layer (`obs-vkcapture`) & XWayland direct frame streaming.
- **Background Interaction**: Wine Agent client post-message integration and Linux kernel `/dev/uinput` virtual device driver.
- **Audio Control**: PipeWire / PulseAudio per-stream hardware-independent audio control.
- **UI Base**: Modern, responsive PySide6 + Fluent-Widgets desktop application suite.
- **Platform Neutral**: 100% decouple from Windows APIs and proprietary COM libraries.
